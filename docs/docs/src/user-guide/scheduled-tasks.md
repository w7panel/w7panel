# 计划任务

计划任务用于让面板按预定时间自动执行某些操作。它适合处理那些“不是现在立刻做，而是需要定时做”的工作。

在当前面板里，计划任务是 **应用管理** 下的独立页面，而不是某个应用详情里的附属按钮。

## 进入计划任务

1. 登录微擎面板。
2. 在左侧菜单进入 **应用管理**。
3. 点击 **计划任务**。

如果你只是想临时进入某个运行中的容器执行一次脚本，那通常更适合去应用详情里的相关入口；如果你希望一件事周期性自动执行，才更适合使用 **计划任务**。

## 适合什么场景

常见场景包括：

- 定时执行脚本
- 定时备份数据
- 定时清理缓存或日志
- 定时调用某些维护命令

如果你的目标是让某件事“自动重复执行”，通常就应该优先考虑计划任务，而不是手动重复操作。

## 新建计划任务

1. 进入 **计划任务** 页面。
2. 点击 **新建**。
3. 填写任务名称。
4. 设置执行周期。
5. 填写需要执行的脚本或命令。
6. 确认保存。

保存后，建议先观察一次任务是否按预期执行，再把它当作长期自动任务使用。

如果你的任务依赖某个应用、目录或运行环境，建议先确认目标对象本身已经稳定可用，再去创建计划任务。

## 编辑、停用或删除计划任务

在计划任务列表中，通常可以对已有任务继续做这些操作：

- 编辑任务配置
- 调整执行周期
- 修改执行内容
- 临时停用任务
- 删除不再使用的任务

如果任务已经在线上稳定运行，修改前最好先确认影响范围。

## 配置任务时要注意什么

- 执行周期要和任务实际耗时匹配
- 执行内容要明确，不要让脚本含义过于模糊
- 涉及删除、清理、覆盖时，要先确认目标路径或目标对象
- 需要依赖文件、目录或环境变量的任务，先确认运行环境可用

## 任务执行异常时先看什么

如果计划任务没有按预期运行，建议先从这几个方向判断：

1. 执行周期是否设置正确
2. 执行脚本或命令本身是否可用
3. 依赖的文件、目录、权限是否正常
4. 任务是否运行了，但执行结果不符合预期

计划任务的关键，不只是“有没有保存成功”，而是“到了时间以后是否真的按预期执行了”。
