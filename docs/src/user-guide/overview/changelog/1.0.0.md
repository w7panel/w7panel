# 1.0.0

**发布日期**: 2026-02-22

## 新增 (Added)
- 新增“网关管理 → AI代理”，支持按域名管理多个 AI 服务提供者、权重与启停，并提供 Key Auth 消费者和模型白名单配置。
- 面板升级通过 `kodata/charts` 中的 Helm Chart 默认安装或升级 `w7panel-pluginwhitedomain` 域名插件和 `w7panel-pluginratelimit` 限流插件，将旧版 Higress 插件配置无损迁移到新版资源，并在校验成功后删除旧资源；迁移失败时自动回滚。
- 新增“网关管理 → 网关插件”，支持基于 Higress WasmPlugin 添加、编辑、启停、卸载以及全局/规则配置。
- 网关插件可关联 MicroApp 前端包；全局配置使用竖向角色菜单，域名规则使用普通用户端横向 Tab，无前端包时回退 YAML。
- 域名管理“更多”仅展示已启用且支持规则配置的插件。
- 响应优化中间件 `ResponseOptimize()`，自动移除 K8s 系统字段（managedFields, finalizers 等）
- API 响应大小减少约 50%，提升加载性能
- 前端 API 配置文件 `src/config/api.ts`（便于未来路由迁移）
- **v5.4 重构计划**: `docs/refactoring/refactoring-plan-v5.4.md`
- 新增 GitHub Actions tag 构建流程：打 Git tag 后自动构建 `w7panel-ui`、同步前端产物到 `w7panel-server/kodata`，并通过 `ko build` 推送镜像

## 变更 (Changed)
- AI 代理模型统一在域名路由配置中维护，服务提供者只配置厂商、凭证、地址、权重和启停状态。
- 面板升级不再重复创建或强制回写旧版域名白名单、限流 WasmPlugin；域名白名单后端读取改为优先识别制品逻辑标签并兼容旧资源名。
- 网关插件的全局和规则配置增加 MicroApp 注入数据日志，便于调试配置上下文，同时避免输出认证凭证。
- 优化域名管理“更多”页面的提示框与插件表格间距。
- 网关插件列表移除“前端包”列、收窄“插件”列并优化顶部操作区间距，前端包关联继续用于打开插件配置界面。
- 网关插件全局配置的竖排菜单固定将创始人端显示在普通用户端上方。
- 清理 `w7panel-ui` 未接入的历史组件、页面和静态资源，并同步更新前端组件文档与微前端事件文档。

## 修复 (Fixed)
- 修复 AI 代理把认证和模型配置写入 `ai-proxy` 无效字段的问题，改为复用 Higress 内置 `key-auth.internal` 和 `request-validation.internal` 插件；提供者使用域名作用域 ID，避免不同域名的同名配置互相覆盖，并在删除域名时清理关联资源。
- 修复通义千问服务提供者无法持久化自定义域名的问题；显式填写的域名（包括默认的 `dashscope.aliyuncs.com`）会写入 Higress `ai-proxy` Provider 配置。
- 修复 AI 服务提供者的 API Token 在未按回车、直接点击保存时丢失的问题。
- 修复删除 AI 服务提供者后残留的服务级规则导致 `ai-proxy` WasmPlugin 整体加载失败的问题；保存配置时同步清理本功能产生的孤儿规则和服务注册。
- 修复 `request-validation.internal` 使用空默认配置导致 WasmPlugin 启动失败的问题，并要求模型白名单校验请求体必须包含 `model` 字段。
- 修复 Key Auth 和模型白名单规则同时设置 `domain`、`ingress` 组合目标后无法命中业务命名空间 Ingress 的问题；域名级插件规则统一仅按域名匹配。
- AI 服务提供者统一写入 Higress 2.2.3 内置 `ai-proxy.internal` 2.0.0 实例，并补齐 `higress.io/resource-definer=higress` 等识别标签，可在 Higress 服务提供者管理列表中查看。
- AI 代理域名列表的“服务提供者”入口更名为“编辑”，统一承载域名路由、认证、模型和服务提供者配置。
- 修复 `request-validation.internal` 使用 `FAIL_CLOSE` 时插件加载异常导致其他域名统一返回 500 的问题，内置认证和请求校验实例统一恢复 Higress 默认的 `FAIL_OPEN` 策略。
- 修复网关插件停用后无法进入全局配置的问题；停用期间仍可修改并保存配置，重新启用后生效。
- 修复网关插件启用、停用和卸载确认框打开时页面短暂出现横向滚动条的问题。
- 修复网关插件配置组件与 Wujie 弹窗组件之间的循环依赖，避免域名策略页面初始化时报 `Cannot access 'gatewayPluginConfig' before initialization`。
- 修复网关插件 YAML 编辑器容器高度为零导致配置内容显示为空的问题。
- 网关插件改为根据 MicroApp `bindings.menu` 判断是否配置前端包，无对应角色菜单时直接显示 YAML。
- 制品安装的网关插件改为按 WasmPlugin 与 MicroApp 共同的 `w7.cc/group-name` 自动关联配置前端包；同组无法唯一匹配时回退 YAML。

### 启动参数规范（2026-02-20）

**问题现象**：
```
serviceaccounts "admin" is forbidden: User "system:serviceaccount:default:default" 
cannot get resource "serviceaccounts" in API group "" in the namespace "default"
```

**根因**：未正确设置环境变量，系统使用 K8S Pod 内 ServiceAccount 而非本地 kubeconfig

**正确启动方式**：
```bash
# 必须设置的环境变量
export CAPTCHA_ENABLED=false
export LOCAL_MOCK=true              # 关键：使用本地 kubeconfig
export KO_DATA_PATH=/path/to/kodata
export KUBECONFIG=/path/to/kubeconfig.yaml  # 必须使用绝对路径

# 启动服务
cd /home/wwwroot/w7panel-dev/dist
./w7panel server:start
```
