# FAQ

本文面向第一次接触微擎面板（W7Panel）的用户，重点回答三类最常见的问题：

- 这套面板适不适合我
- 安装或环境出问题时先查哪里
- 实际使用中遇到问题应该先看哪一类文档

如果你已经准备开始操作面板，建议把这篇 FAQ 当成“快速判断入口”，而不是详细操作手册。

## 一、入门理解

### 微擎面板一定要配合 Kubernetes 使用吗？

是的。W7Panel 的核心定位就是 Kubernetes 场景下的云原生应用管理平台。

如果你完全不使用 Kubernetes，那么 W7Panel 并不是为这类环境设计的。

### 我不会 `kubectl`，还能使用微擎面板吗？

可以。W7Panel 的一个重要目标，就是降低 Kubernetes 的使用门槛。

很多原本需要命令行完成的事情，都可以通过界面完成，例如：

- 创建和部署应用
- 查看运行状态、日志和事件
- 管理域名、证书和访问入口
- 浏览容器文件、上传下载和在线编辑
- 查看存储资源和卷使用情况

不过，如果你能理解一些基础概念，例如命名空间、Pod、Service、Ingress、存储卷，会更容易理解面板里的功能含义。

## 二、安装与环境

### 安装完成后打不开面板

确认使用的是安装结果中的地址。首次访问通常为 `http://服务器地址:9090`。检查服务器地址是否正确、服务器防火墙和云平台访问规则是否允许访问，以及安装是否真正完成。

如果自动识别的服务器地址不正确，请管理员检查安装参数。不要反复在同一台服务器上重复安装来尝试修复。

### 安装识别的公网地址不正确，或者 IPv6 环境访问异常

先核对服务器实际地址、安装结果和域名解析。不同安装器版本支持的参数可能不同，请按当前安装页面说明处理；不要直接套用历史 `PUBLIC_IP` 或 `INTERNAL_IP` 命令。

### 多节点中部分服务器连不上

在节点管理检查节点地址和在线状态。服务器地址变化、节点网络或资源不足都可能影响连接，记录异常时间与节点名称后交给管理员处理。

### 安装长时间没有完成

先确认服务器网络、镜像下载和组件启动情况。系统安全策略也可能影响服务启动，请管理员查看服务日志，不要直接关闭安全组件反复安装。

### 误删面板应用怎么办

保留原存储和配置，联系管理员确认当前部署版本、安装方式与备份，再选择恢复方案。重新安装不能保证找回已删除的数据。

### 忘记管理员密码怎么办

联系有服务器管理权限的人员重置。重置需要在服务器环境中操作。不要使用历史教程中的旧程序名称或默认弱密码命令。

## 三、使用与排查

### 登录后找不到某个菜单或按钮

确认当前账号是否有权限，以及对应应用或组件是否已安装。列表为空时，也要检查当前命名空间，也就是页面选择的项目分区。

### 应用显示已安装，但不能访问

先在应用详情确认是否正常运行，再看事件和日志。运行正常后，检查域名解析、目标端口和证书，详见 [应用管理](../app-management.md) 和 [域名管理](../domain-management.md)。

### 多个应用同时变慢或出错

进入 **集群管理 → 概览** 查看资源占用，再检查 **节点管理** 中是否有服务器异常。磁盘或内存不足可能影响多个应用。

### 上传或修改文件失败

核对应用和目录，检查文件权限、剩余空间以及页面大小限制。配置文件可能是只读的，需要从应用配置入口修改，见 [文件管理](../file-management.md)。

### 文件为什么在应用重建后消失

文件可能放在临时目录。重要数据应保存到专门的存储空间，见 [存储管理](../storage-management.md)。

### 域名已经添加，为什么还打不开

在面板里添加域名后，还需要在域名服务商处设置解析。确认解析地址正确，再检查应用运行情况。使用 HTTPS 时还需要有效证书。

### 配置插件后网站打不开

如果修改的是全局配置，到 **网关管理 → 网关插件** 关闭对应全局状态；如果修改的是单个域名规则，在该域名的 **更多** 中关闭该规则。两个开关分别控制各自设置。

### 提交问题时提供什么

提供出错时间、操作步骤、应用名称和页面错误提示。截图或日志中遮住密码、访问密钥及个人信息，便于管理员定位问题。
