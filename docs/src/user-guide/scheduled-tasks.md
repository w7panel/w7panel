# 计划任务

计划任务用于让面板按预定时间自动执行某些操作。它适合处理那些“不是现在立刻做，而是需要定时做”的工作。

在当前面板里，计划任务是 **应用管理** 下的独立页面，而不是某个应用详情里的附属按钮。

## 进入计划任务

1. 登录微擎面板。
2. 在左侧菜单进入 **应用管理**。
3. 点击 **计划任务**。

如果你只是想临时进入某个运行中的容器执行一次脚本，那通常更适合去应用详情里的相关入口；如果你希望一件事周期性自动执行，才更适合使用 **计划任务**。

## 适合什么场景

常见场景包括：

- 定时执行脚本
- 定时备份数据
- 定时清理缓存或日志
- 定时调用某些维护命令

如果你的目标是让某件事“自动重复执行”，通常就应该优先考虑计划任务，而不是手动重复操作。

## 新建计划任务

1. 进入 **应用管理 → 计划任务**，点击添加任务。
2. 填写容易识别的任务名称。
3. 选择 **周期执行** 或 **单次执行**。周期任务还需要设置执行时间。
4. 设置运行所需的程序包（页面中称为“镜像”）、命令和数据目录。
5. 有多个执行部分时，先确认它们能否同时运行；存在先后依赖时，请任务提供者准备完整的执行安排。
6. 保存后查看执行记录和日志，确认任务完成了预期工作。

命令和运行环境由任务提供者准备。仅填写任务名称和时间，并不会自动生成备份。

### 执行方式的区别

| 选项 | 含义 |
| --- | --- |
| 周期执行 | 按设置的日期和时间重复运行 |
| 单次执行 | 执行一次，适合临时处理工作 |
| 并发执行 | 多个执行部分一起开始，彼此不能依赖先后结果 |
| 顺序执行 | 当前页面有此选项，但不能仅凭选择它保证前后顺序；有依赖的工作请让任务提供者安排 |

### 使用示例：运行一个简单任务

第一次使用可以先验证执行流程，不操作业务数据：

1. 新建 **单次执行** 任务，名称填写 `hello-task`。
2. 镜像填写 `busybox:1.36`，目标服务器需要能下载这个镜像。
3. 在 **运行命令** 中开启 **简易模式**，填写：

```sh
echo "任务运行成功"
date
```

4. 不需要连接数据目录，保存后打开执行记录和日志。
5. 日志中应出现“任务运行成功”和执行时间，任务随后结束。

需要定时运行时，再新建周期任务，使用相同镜像和命令，通过时间选择器设置周期。这个例子只验证任务能否运行；实际备份还需换成备份工具、命令，并连接要备份的数据目录与备份保存位置。

## 编辑、停用或删除计划任务

周期任务可以通过列表开关暂停或恢复后续安排；暂停不代表已经运行的那一轮会立即停止。

编辑周期任务会更新原来的安排。编辑单次任务后保存，会创建一次新的执行，不只是改写历史记录。新建单次任务保存后也可能马上运行，确认执行内容后再提交。

“执行一次”用于临时运行周期任务，不会改变它原来的周期。单次任务中的“立即执行”会再次创建执行记录。不再需要时可以删除，操作前检查正在运行的任务。

如果上一轮尚未结束就到下一次执行时间，任务可能重叠运行。备份或清理任务应预留足够间隔，表单中的“顺序执行”也不能用来阻止轮次重叠或保证各部分依次运行。

## 配置任务时要注意什么

- 执行周期要和任务实际耗时匹配
- 执行内容要明确，不要让脚本含义过于模糊
- 涉及删除、清理、覆盖时，要先确认目标路径或目标对象
- 需要依赖文件、目录或环境变量的任务，先确认运行环境可用

## 任务执行异常时先看什么

1. 检查选的是周期任务还是单次任务，时间设置是否正确。
2. 查看执行记录，区分“没有运行”和“运行后报错”。
3. 检查运行程序、命令、文件路径、权限和数据目录。
4. 向任务提供者确认时间设置是否符合服务器使用的时区。

### 查看执行记录和日志

列表分为 **周期执行** 和 **单次执行**。检查上次执行时间，打开执行记录查看日志。需要立即验证时，可以使用列表提供的 **执行一次** 或 **立即执行**。

涉及删除、覆盖或付费操作的任务，不要为了测试反复执行。
