# 网关插件

网关插件基于 Higress `WasmPlugin` 管理，用于给网关增加鉴权、限流、缓存等扩展能力。

## 进入插件管理

进入 **网关管理 → 网关插件**。列表展示 `higress-system` 命名空间中的全部 `WasmPlugin`，包括插件名称、支持范围和运行状态。插件关联的前端包仅用于打开配置界面，不在列表中单独展示。

## 添加插件

1. 点击 **添加插件**。
2. 填写 Kubernetes 资源名称、显示名称、镜像地址、执行阶段和优先级。
3. 选择支持范围：
   - **支持全局配置**：默认勾选，配置对整个网关生效。
   - **支持规则配置**：勾选后，插件会出现在应用域名管理的“更多”中。
4. 手工添加时可选填写关联的 MicroApp 名称；通过制品安装时，面板会根据插件与 MicroApp 共同的 `w7.cc/group-name` 自动关联。
5. 保存后即可在列表中管理插件。

至少需要选择一种支持范围。

## 配置方式

- 制品中同一 `w7.cc/group-name` 下唯一的 MicroApp，且对应角色的 `bindings.menu` 包含菜单时，面板按照现有 MicroApp 下载、代理和 Wujie/iframe 加载流程显示操作界面。
- 同组 MicroApp 缺失或存在多个匹配时，不自动选择前端包，直接显示 YAML 配置。
- 未配置 MicroApp、MicroApp 不包含前端包或前端包加载失败时，显示 YAML 配置编辑器。
- 全局配置的 MicroApp 菜单使用左侧竖排布局，支持创始人端和普通用户端菜单。
- 域名规则配置只读取普通用户端菜单，并使用横向 Tab 布局。

## 启用、停用和卸载

- **停用**：插件从域名管理“更多”中隐藏，同时停止全局配置和所有域名规则；仍可从插件列表进入、修改并保存全局配置，修改内容会在重新启用插件后生效。原开关状态会保存，重新启用时恢复。
- **启用**：恢复停用前的全局配置和规则开关。
- **卸载**：删除 `WasmPlugin` 及其中的全部配置，操作不可恢复。

## 配置域名规则

1. 进入 **应用管理 → 应用详情 → 域名管理**。
2. 打开目标域名的策略配置。
3. 进入 **更多**。
4. 找到已启用且支持规则配置的插件。
5. 开启当前规则并进入配置。

停用或卸载的插件不会显示在这里。
