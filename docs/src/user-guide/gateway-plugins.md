# 网关插件使用指南

网关插件可以为网站增加访问控制等能力。本指南说明插件的安装流程，并以域名白名单插件为例介绍如何使用。

## 开始前

操作前请确认：

- 已经登录面板；
- 账号可以访问制品市场和网关管理；
- 需要配置的网站已经添加到面板，并且域名可以正常访问。

## 安装插件

所有网关插件都从制品市场安装。

1. 在面板左侧进入 **应用管理**。
2. 点击 **制品市场**。
3. 在市场中搜索需要的插件名称。
4. 点击插件，进入详情页面。
5. 点击 **安装**，按照页面提示完成安装。
6. 安装完成后，进入 **网关管理 → 网关插件**。
7. 在列表中找到刚安装的插件，确认状态为 **已启用**。

如果列表中没有看到插件，先确认安装任务是否成功，再刷新页面。

## 配置域名白名单

假设网站使用下面两个域名：

- `example.com`
- `api.example.com`

希望只允许这两个域名通过网关访问。

### 第一步：安装域名白名单插件

1. 进入 **应用管理 → 制品市场**。
2. 搜索“域名白名单”。
3. 打开插件详情并完成安装。
4. 安装完成后进入 **网关管理 → 网关插件**。

### 第二步：添加允许访问的域名

1. 找到“域名白名单”插件。
2. 点击 **全局配置**。
3. 进入 **白名单配置**。
4. 点击 **添加**。
5. 输入 `example.com`，打开这一行的开关。
6. 再添加一行，输入 `api.example.com`，同样打开开关。
7. 点击 **保存**。

填写域名时只填写域名本身。例如填写 `example.com`，不要填写：

```text
https://example.com
example.com:443
example.com/admin
```

### 第三步：设置拦截提示

在同一个配置页面进入 **错误页配置**，可以设置其他域名被拒绝时看到的内容。

例如：

| 配置项 | 填写内容 |
|--------|----------|
| 错误码 | `404` |
| 内容 | `not found` |

填写后点击 **保存**。

### 第四步：确认是否生效

1. 访问 `https://example.com`，网站应正常打开。
2. 访问 `https://api.example.com`，接口应正常响应。
3. 使用一个没有加入白名单的域名访问网关，应看到 HTTP 404 和 `not found`。

如果允许的域名也被拒绝，请检查域名是否拼写正确、该行开关是否开启，以及插件状态是否为“已启用”。

## 暂停或恢复插件

进入 **网关管理 → 网关插件**：

- 点击 **停用**，插件规则会暂时停止，但已经填写的配置会保留；
- 点击 **启用**，恢复原有配置。

如果错误配置导致网站无法访问，可以先停用插件恢复访问，修改配置后再启用。

## 常见问题

### 安装后找不到插件

返回制品安装页面确认安装是否成功，然后刷新 **网关管理 → 网关插件**。

### 找不到“全局配置”按钮

该插件可能只支持针对单个域名配置。进入应用的 **域名管理 → 域名策略 → 更多** 查找插件。

### 域名策略中找不到插件

确认插件已经安装并启用。如果仍未显示，说明该插件不支持针对单个域名配置。

### 保存后没有生效

依次检查：

1. 插件是否已启用；
2. 当前域名的规则是否已开启；
3. 配置的域名是否与实际访问域名一致；
4. 浏览器或接口请求是否经过当前网关。
